# Fotos de personas — Solvo Global

Retratos de las fichas de talento del showcase, que el admin administra desde el formulario del perfil de búsqueda.

**Convención**: `person-01.jpg` … `person-08.jpg`. Cuadradas, ~400×400px, rostro centrado — se muestran recortadas en círculo.

Fuente canónica: `<vault>/shared/design-system/solvo-global/assets/people/`. Esta carpeta es una copia local commiteada en el bundle; al actualizar las fotos, re-copiarlas desde ahí. Los mismos retratos alimentan el showcase de la landing de agendamiento (`email-cold-outreach-booking-landing-release-2`), de modo que la ficha que el admin edita acá sea la que el prospecto ve allá.
